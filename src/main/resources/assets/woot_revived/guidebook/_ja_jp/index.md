# Woot Revivedって何?

Woot Revivedは、モブをスポーンさせずに直接ドロップ品を生成するティア方式のマルチブロックシステムを導入し、モブの討伐をシミュレートします。疑似スポナーでファクトリーを構築し、バイタリティ燃料と必要に応じて特定のアイテムを搬入すれば、ドロップ品が自動的にチェストに生成されます。
