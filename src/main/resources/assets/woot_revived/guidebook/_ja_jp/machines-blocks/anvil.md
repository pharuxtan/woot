# スティジアンの金床

<BlockImage id="stygian_anvil" scale="5"/>

<ItemImage id="stygian_anvil" scale="0.5"/>スティジアンの金床は、Woot Revivedでの旅の出発点です。

これを使ってクラフトするには、<ItemImage id="stygian_hammer" scale="0.5"/>スティジアンハンマーで右クリックする必要があります。詳細は[始め方](../getting-started.md)をご覧ください。

何も持たずに金床をShiftキーを押しながらクリックすると、アイテムを回収できます。

スティジアンの金床はアイテムパイプと<ItemImage id="netherite_magmator" scale="0.5"/> [マグメイター](magmator.md)を使用することで自動化できます。
